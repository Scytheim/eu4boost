# eu4boost

**유로파 유니버설리스 4(EU4) 1.37.5.0 "Inca"용 성능 플러그인**입니다. 게임 파일(eu4.exe)은 고치지 않고, 게임이 실행될 때 메모리 안에서만 느린 부분을 빠른 방식으로 바꿉니다.

- 100년 관전 시험에서 **같은 기간을 1.31배 빠르게** 진행했습니다(36.2분 → 27.7분).
- 저장 한 번(철인모드 자동 저장 포함)에 걸리는 시간이 **848ms → 245ms**로 줄었습니다.
- 기본 기능은 게임 결과를 바꾸지 않습니다. 원래 코드와 결과를 직접 비교해서 확인했습니다.

> 필요한 것: Windows 64비트, EU4 **1.37.5.0** (Steam), **[EU4dll](https://github.com/matanki-saito/EU4dll)**.
> EU4dll은 한글·일본어 패치를 설치하기 위해 설치하는 DLL입니다. 이 플러그인은 EU4dll이 게임 폴더의 `plugins` 폴더에서 읽어 들입니다.

## 1. 사용 전후 성능

측정 PC: Ryzen 5 9600X(6코어 12스레드), Windows 11.

### 게임 진행 속도 (100년 관전)

1600년 1월 1일 세이브를 관전 모드 5배속으로 1700년 1월 1일까지 진행했습니다. 플러그인 끔/켬을 번갈아 3번씩 쟀습니다(모드 7개 플레이세트).

| | 플러그인 없음 | 플러그인 사용 | 차이 |
|---|---|---|---|
| 100년 걸린 시간 | 36.18분 | **27.67분** | **1.31배 빠름** (−23.5%) |
| 100년 동안 쓴 CPU 총량 | 84.3 코어·분 | 72.0 코어·분 | −15% |
| 게임 메모리 | 2.97GB | 3.36GB | +0.4GB |

- 3번 각각: 없음 35.89 / 36.67 / 35.98분, 사용 27.96 / 27.28 / 27.78분.
- 이 측정에서는 실험 기능 하나(나라 정보 미리 계산, 약 1.7%)가 켜져 있었습니다. 나머지는 기본 설정입니다.

### 후반부 게임 진행 속도 (1874년 세이브)

나라가 크고 전쟁이 많은 후반부(1874년 7월, 철인모드, 모드 플레이세트) 세이브를 5배속으로 1880년 1월 1일까지(5.5년) 진행했습니다. 세 가지 설정을 번갈아 2번씩 쟀습니다.

| | 1차 | 2차 | 평균 | 플러그인 없음 대비 |
|---|---|---|---|---|
| 플러그인 없음 | 4.05분 | 3.95분 | 4.00분 | |
| 플러그인 기본 기능만 | 2.98분 | 2.86분 | 2.92분 | 1.37배 빠름 |
| 실험 기능까지 모두 켬 (배포 설정) | 2.67분 | 2.75분 | **2.71분** | **1.48배 빠름** |

### 저장(철인모드 자동 저장) 시간

| | 플러그인 없음 | 플러그인 사용 |
|---|---|---|
| 저장 1번(1543년 모드 세이브) | 848ms | **245ms** |

저장 파일 내용은 원래 방식과 똑같습니다(압축을 풀면 바이트 단위로 동일).

### 매월 1일 처리 (실험 기능, 배포 설정에서 켬)

게임은 매월 1일에 프로빈스마다 "그 프로빈스와 관련된 가장 강한 나라의 modifier 설명 문장"을 처음부터 다시 만듭니다(출처 300개 이상). 같은 나라에 대한 문장은 같은 날 안에서 똑같으므로, 나라별로 한 번만 만들고 나머지는 복사합니다. 문장은 게임이 만든 것과 바이트 단위로 같습니다(5년 동안 13만 7천 번 비교).

| | 원래 | 사용 | 설정 키 |
|---|---|---|---|
| 문장 하나(1874년 세이브) | 82.0µs | 2.65µs (31배) | `[modifiers] prov_text_cache` |
| 매월 1일 하루 | | 약 190ms 짧아짐 | |

### 후반부 AI (실험 기능, 배포 설정에서 켬)

나라가 크고 전쟁이 많은 후반부(1874년 세이브)에는 AI 계산이 하루 처리의 약 20%를 차지합니다. 아래 기능은 이 계산을 빠르게 합니다. 각 기능은 원래 계산과 결과가 같은지 수천만 번 비교해 확인했습니다. 아직 실험 단계지만 배포하는 설정 파일에서는 켜져 있습니다.

| 기능 | 원래 | 사용 | 설정 키 |
|---|---|---|---|
| AI가 건물 지을 곳 고르기(큰 나라 한 번) | 90.6ms | 26.8ms (3.4배) | `ai_prov_split` |
| AI 평화 협상안의 공격적 확장(AE) 계산(한 번) | 61.0µs | 27.6µs (2.2배) | `ai_ae_cache` |
| 부대 AI의 "이동 가능?" 검사(한 번) | 0.34µs | 0.085µs (4배) | `ai_army_fast` |

## 2. 사용하면 무엇이 영향을 받나요?

### 바뀌지 않는 것

- **게임 파일**: eu4.exe와 게임 데이터는 그대로입니다. 플러그인 파일 두 개를 지우면 완전히 원래대로 돌아갑니다.
- **세이브**: 형식과 내용이 원래와 같습니다. 플러그인 없이도 그대로 불러올 수 있습니다.
- **게임 결과**
  - 기본으로 켜지는 기능은 계산 순서만 바꾸거나 같은 결과를 더 빨리 내는 것들입니다.
  - 고정 난수(seed)로 1년 이상 돌려 매일 게임 상태가 같은지 확인했습니다.
  - 일부 기능은 원래 함수와 매번 결과를 비교해 확인했습니다.
  - 예외: 실험 기능 "나라 정보 미리 계산"(`[country] parallel_refresh`, 배포 설정에서 켬)은 일부 캐시 값을 같은 날 조금 일찍 계산해서, 원래와 99.9% 같지만 완전히 같지는 않습니다. 원하지 않으면 `parallel_refresh=0`으로 끄세요.
- **게임 체크섬**: 파일을 바꾸지 않으므로 체크섬도 그대로입니다.

### 바뀌는 것

| 항목 | 내용 |
|---|---|
| 메모리 | 게임 메모리 관리를 더 빠른 방식(mimalloc)으로 바꿔서 메모리를 약 0.4GB 더 씁니다 |
| CPU | 게임이 주 스레드를 CPU 하나에 묶어 두는 것을 풀고, 여러 코어를 더 고르게 씁니다. 전체 CPU 사용률은 조금 늘고, 같은 기간에 쓰는 CPU 총량은 줄어듭니다 |
| 화면·입력 | 기본 설정에서는 원래 게임과 같습니다. 5배속에서 2~3일에 한 번만 화면을 그리는 기능은 따로 켜야 합니다 |
| Paradox 온라인 서비스 | 계정·온라인 서비스 응답 확인을 매 프레임이 아니라 0.1초마다 합니다 |
| 크래시 방지 | 게임 자체 버그로 나는 크래시 두 가지(툴팁이 지워진 정보를 읽는 경우, 합병 때 외교 관계가 없는 경우)를 막습니다. 그 상황에서만 동작합니다 |
| 로그 | `plugins\eu4boost.log`에 동작 기록을 남깁니다 |

### 주의할 점

- **EU4 1.37.5.0 전용입니다.** 게임 버전이 다르면 각 기능이 스스로 꺼지고 로그에 남깁니다(크래시 대신 아무것도 안 함).
- **멀티플레이는 검증하지 않았습니다.** 멀티에서 쓰려면 모든 참가자가 같은 버전·같은 설정을 쓰는 것을 권장합니다.
- **철인모드 콘솔 단축키**(Ctrl+Alt+C, 기본 꺼짐)는 철인모드에서 콘솔 명령을 쓸 수 있게 하는 기능입니다. 켜고 쓰는 것은 각자 판단입니다.
- 실험 기능(위 표의 `ai_*`, `prov_text_cache`, 나라 정보 미리 계산)은 배포하는 설정 파일에서 켜져 있습니다. 문제가 생기면 `eu4boost.ini`에서 해당 값을 `0`으로 바꾸세요. 설정 파일에 값이 없으면 꺼진 것으로 동작합니다.

## 3. 설치

1. **EU4dll이 설치돼 있는지 확인합니다.** 게임 폴더(`...\steamapps\common\Europa Universalis IV`)에 `plugins` 폴더와 그 안의 `plugin64.dll`이 있으면 설치된 것입니다. 없으면 한글 패치(EU4dll)를 먼저 설치하세요.
2. 이 저장소의 **[Releases](../../releases/latest)** 에서 `eu4boost_v버전.zip`을 내려받습니다.
3. 압축을 풀어 나온 `plugins` 폴더를 게임 폴더에 그대로 덮어씁니다. 결과는 다음과 같아야 합니다.
   ```
   Europa Universalis IV\plugins\eu4boost.dll
   Europa Universalis IV\plugins\eu4boost.ini
   ```
4. 게임을 켭니다. `plugins\eu4boost.log`가 생기고 `allocator: mimalloc active` 같은 줄이 있으면 정상입니다.

**제거**: `plugins` 폴더에서 `eu4boost`로 시작하는 파일을 모두 지웁니다.

**설정**: `plugins\eu4boost.ini`를 메모장으로 열어 값을 바꿉니다. 각 항목 위에 설명이 있습니다. 바꾼 설정은 게임을 다시 켜야 적용됩니다.

**업데이트**: 0.4.2부터는 새 버전이 나오면 자동으로 받습니다(아래 "자동 업데이트"). 0.4.1 이하를 쓰고 있다면 0.4.2는 위 방법으로 한 번 직접 설치해 주세요.

## 자동 업데이트

0.4.2부터 게임을 켜면 약 20초 뒤 eu4boost가 이 저장소의 최신 릴리스를 확인합니다. 더 새 버전이 있으면 뒤에서 내려받아 두고, **다음에 게임을 켤 때부터** 새 버전을 씁니다. 게임 시작이나 진행 속도에는 영향이 없습니다.

- **안전**: 릴리스 zip 안의 `eu4boost.dll`은 개발자의 서명 키로 서명되어 있고(서명은 zip의 주석에 들어 있어 압축을 풀어도 파일로 생기지 않습니다), 플러그인에 들어 있는 공개 키로 서명이 맞을 때만 설치합니다. 서명이 맞지 않으면 아무것도 바꾸지 않습니다.
- **바뀌는 것**: `plugins\eu4boost.dll`만 바뀝니다. `eu4boost.ini`(내 설정)는 그대로 둡니다. 이전 DLL은 다음 실행 때까지 `eu4boost.dll.old`로 남아, 문제가 있으면 이름을 되돌려 쓸 수 있습니다.
- **보내는 것**: 게임을 켤 때 GitHub에 최신 릴리스를 묻는 요청 한 번(그리고 새 버전이 있을 때 내려받기)뿐입니다. 이때 GitHub에 내 IP 주소가 보입니다. 다른 정보는 보내지 않습니다.
- **끄기**: `plugins\eu4boost.ini`의 `[update] auto=0`.

## 크래시·느려짐 보고 (개인정보 처리 안내)

0.4.1부터 eu4boost는 게임이 튕기거나, 멈추거나, 비정상 종료되거나, 눈에 띄게 느려질 때(화면이 2초 넘게 멈칫, 저장 창·불러오기 목록이 0.3초 이상, 불러오기가 90초 이상) 원인 분석용 보고를 남기고, **동의한 경우에만** 다음 실행 때 개발자에게 보냅니다. 처음 실행할 때 한 번 예/아니오로 묻습니다. 느려짐 보고는 하루에 한 번까지입니다.

- **보내는 것**: 오류 종류와 위치(모듈+주소), 호출 기록, 레지스터, 메모리 사용량, 게임 날짜, 느려진 동작과 걸린 시간·그 순간의 호출 기록, 세이브 파일 수와 크기, 최근 저장 기록(저장 시각·게임 날짜·크기·쓰인 방식, 0.4.2부터), 비정상 종료 직전 상태(1분마다 기록한 메모리 사용량·남은 메모리·게임 날짜, 0.4.2부터)(이름·내용은 아님), 플러그인 버전·설정·로그, 게임 버전·모드 목록(`dlc_load.json`과 각 모드 `.mod` 파일의 이름·버전·지원 게임 버전·창작마당 번호, 0.4.2부터. 모드 폴더 경로는 보내지 않음), 게임 크래시 폴더의 `meta.yml`·`exception.txt`, 게임 로그(`game.log`, `error.log`의 마지막 부분, `system.log`의 하드웨어 줄), PC 사양(CPU, 스레드 수, RAM, 그래픽카드, Windows 빌드, 언어), `plugins` 폴더의 파일 이름·크기와 EU4dll 해시, 함께 로드된 DLL 이름
- **보내지 않는 것**: 세이브 파일, 메모리 덤프(`minidump.dmp`), Windows 사용자 이름·PC 이름·사용자 폴더 경로(보내기 전에 지움), Paradox·Steam 계정 정보(실행 인자의 계정 ID·세션 토큰도 지움)
- **목적**: 크래시·멈춤·느려짐의 원인을 찾아 고치는 것에만 씁니다.
- **받는 곳**: Cloudflare Workers(전달만 하고 저장하지 않음, IP를 기록하지 않음)를 거쳐 GitHub 비공개 저장소(미국)에 이슈로 보관됩니다. 개발자만 볼 수 있습니다.
- **보관 기간**: 해결되면 지우고, 늦어도 1년 뒤에 지웁니다.
- **거부·철회**: 동의하지 않아도 플러그인 기능은 모두 같습니다. `plugins\eu4boost.ini`의 `[report] upload=0`으로 언제든 끌 수 있고, 보고 자체를 남기지 않으려면 `capture=0`으로 둡니다. 보낸 보고를 지워 달라면 GitHub 이슈로 알려 주세요(보고 ID는 `plugins\crash_reports\sent`의 파일 이름입니다).
- **확인**: 보낸 내용은 `plugins\crash_reports\sent`에 JSON 파일로 그대로 남습니다. 아직 안 보낸 보고는 `pending`에 있습니다.

## 문제가 생기면

- 게임이 켜지지 않거나 크래시가 나면, 먼저 `plugins\eu4boost.dll`을 다른 곳으로 옮겨 플러그인 없이 되는지 확인해 주세요.
- 이슈를 올릴 때는 `plugins\eu4boost.log`(직전 실행은 `eu4boost_prev.log`)를 함께 첨부해 주세요.
- 글자가 깨지거나 로딩 중 크래시가 나면 `[allocator]`의 `zero_fill=1`을 시도해 보세요(EU4dll 호환 설정).

## 개발

- 빌드: `sh build.sh` → `build/eu4boost.dll`. Windows는 Git Bash + llvm-mingw, Linux/WSL은 clang + lld + mingw-w64를 씁니다.
- 테스트: `sh test/run_tests.sh`(스모크 테스트 13개).
- 릴리스 만들기: `sh tools/release.sh` (아래 "릴리스 올리는 법").
- 개발 문서: [docs/HANDOFF.md](docs/HANDOFF.md), 분석 기록 [docs/ANALYSIS_LOG.md](docs/ANALYSIS_LOG.md).
